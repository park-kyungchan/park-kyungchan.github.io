# 07_DESIGN_TOKENS — 브랜드·디자인 토큰

## 브랜드
- 플랫폼: **탐구랩** / Tamgu Labs · 랩: **입체 탐구랩** (`{영역} 탐구랩` 패턴)
- 로고 방향: 워드마크 — "탐구랩"을 Gaegu 손글씨로, 받침 ㅂ 안에 정육면체 와이어프레임 모티프. 잉크색 단색 + amber 포인트 1개. (제작은 Phase 2)
- 톤: 교과서적 정확·격식. 손글씨는 "탐구 질문"과 브랜드 표기에만 — 본문·데이터는 절대 손글씨 금지.

## 컬러 (현행 R010에서 승격 — 단일 출처 `packages/tokens`)
```
--ink:        #26324b   본문·선·다크 패널
--accent:     #41608f   구조 강조·단원 번호·링크
--amber:      #b97a2e   포인트·하이라이트(진)
--amber-soft: #d9a05b   하이라이트(연)·단면 채움
--paper:      #f7f4ec   배경
--panel:      rgba(255,255,253,0.93) + blur(14px)   플로팅 패널
--solid-face: #dde6f3   3D 기본 면
--grid:       rgba(38,50,75,0.05)  모눈 (28px)
```
랩별 확장 시: ink/paper/amber 고정, accent만 랩별 변주 허용 (oklch 동일 채도·명도 유지).

## 타이포
| 역할 | 폰트 | 규칙 |
|---|---|---|
| 브랜드·탐구 질문 | Gaegu 700 | 손글씨는 이 두 곳만 |
| 제목·단원 번호 | Gowun Batang 700 | 로마 숫자 단원 표기 Ⅰ·Ⅱ·Ⅲ |
| 본문·UI | Noto Sans KR 400/500/700 | 최소 12.5px, 노트 본문 13.5px/1.7 |

## 컴포넌트 규약 (플로팅 패널 시스템)
- 패널: radius 16, border rgba(38,50,75,.14), shadow `0 14px 34px rgba(38,50,75,.16)`, 등장 `floatIn .5s cubic-bezier(.2,.9,.25,1)`
- 헤더: 드래그 그립 + 최소화(–) + 접기(▾/▸). 더블탭=최소화, 플링/화면 밖 드래그=숨김, 우측 트레이 알약으로 복원
- 독: ink 배경 알약, 재생 ▶/■, 진행바 amber-soft
- 터치 타깃 ≥ 44px (dock 원형 버튼 40px → Phase 2에서 44px로 상향)
- 모션 기본값 최대(10). `motionScale` 토큰으로 전 랩 공통 제어. 상태 알림 칩 `chipIn .35s`

## 금지
그라데이션 배경, 이모지, 좌측 보더 액센트 카드, 손글씨 폰트의 본문 사용, 랩별 임의 신규 컬러.
