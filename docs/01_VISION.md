# 01_VISION — 탐구랩 플랫폼 비전

## 한 줄 정의
학생이 **혼자서 끝까지** 수학적 대상을 조작·관찰·추론하게 만드는 인터랙티브 기하 탐구 플랫폼.

## 브랜드 계층
- 플랫폼: **탐구랩** (Tamgu Labs) — 상위 브랜드, 홈 화면의 주인
- 랩: **입체 탐구랩** (파일럿) → 향후 평면 탐구랩, 작도 탐구랩 … `{영역} 탐구랩` 패턴
- 네이밍 근거: 사용자가 확정한 "입체 탐구랩 유지 + 플랫폼명 상위 신설". 랩 이름의 `탐구랩`을 패밀리 브랜드로 승격 — 확장 시 추가 네이밍 비용 0.

## 사용자
| 페르소나 | 핵심 니즈 | 설계 귀결 |
|---|---|---|
| 중1 자습생 | 막혔을 때 스스로 뚫고 나가기 | dynamic scaffolding branches (03) |
| 1:1 교사 | 학생이 어디서 어떻게 막혔는지 파악 | branch 경로 추적 데이터 (04) |

## 성공 정의 (6개월, 사용자 확정)
학생 개별 dynamic scaffolding이 가능한 **다양한 branch**와, 이를 감사/추적하는 **데이터셋 인프라**가 다각도로 구축된 상태. → 06_ROADMAP의 Phase DoD로 분해됨.

## IA (멀티 랩)
```
홈 (탐구랩)                      ← 단원/랩 선택. 신설
└─ 입체 탐구랩                    ← 현행 R010 셸
   ├─ Ⅰ 다면체: 관찰실 · 정다면체 판정 · 오일러 · 전개도 · 단면
   ├─ Ⅱ 회전체: 생성 · 단면
   └─ Ⅲ 심화: 축구공 · 최단거리
```
- 홈은 랩 카드 그리드 + 랩별 진행 상태(로컬). 랩 진입 = SPA 라우트 전환 (`/#/solid`).
- 당분간 랩 1개여도 홈을 먼저 만든다 — 멀티 랩 라우팅·진행 상태 계약을 파일럿에서 확정하기 위함.

## 범위 가드레일
- 커리큘럼 확장은 입체도형 완성 후 (사용자 확정). 단, 엔진·셸은 2D 랩을 수용 가능한 계약으로 설계 (02).
- 교사 도구는 점진 확장 — 지금은 학생 탐구 플랫폼 완성이 우선 (사용자 확정).
